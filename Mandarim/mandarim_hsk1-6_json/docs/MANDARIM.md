# Mandarim para África lusófona — HSK 1 → 6

Pasta Drive `Mazza_mandarim`: HSK Standard Course 1–6 e New Practical Chinese Reader 1–6.
São manuais protegidos. **Não entram diálogos, exercícios nem áudios desses livros.**
Servem só de mapa de níveis (como o PET serviu para o inglês).

| Pacote | Vizinho HSK | Função |
|--------|-------------|--------|
| hsk1 | HSK 1 (~150 palavras) | Cumprimentar, nome, números, família, comida |
| hsk2 | HSK 2 | Passado leve, planos, comparações simples |
| hsk3 | HSK 3 | Experiências, opinião curta, texto de 5–8 frases |
| hsk4 | HSK 4 | Argumento simples, trabalho, notícia curta |
| hsk5 | HSK 5 | Texto contínuo, registo, matiz |
| hsk6 | HSK 6 | Precisão, hedging, texto longo |

UI em português de Moçambique. Alvo: chinês mandarim (simplificado + pinyin).
África: um detalhe local por ecrã (马普托, 小巴, 芒果). Sem postal.

Cada frase no JSON tem `zh`, `pinyin`, `pt`, `audioKey`.
A app faz clique-para-ouvir com TTS `zh-CN` (rate ~0.85) ou CDN.
