# Inglês África Lusófona — pacote de conteúdo A1–C1

Conteúdo original para a app. Inspiração de estrutura: família Cambridge
(Movers → Key → PET → First → Advanced). Nada copiado dos sample papers.

Moçambique e a África lusófona aparecem quando a cena é local (chapa, mercado,
fronteira, calor, espera no terminal). Nas unidades de argumento, media ou
trabalho o inglês é o do mundo — um detalhe local por ecrã chega.
